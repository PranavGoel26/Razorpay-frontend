## 🧪 How to Run Locally  

```bash
# Clone the repo
git clone https://github.com/PranavGoel26/Razorpay-frontend.git

# Navigate into folder
cd discordClone

# Install dependencies
npm install

# Start Tailwind build
npx tailwindcss -i ./main.css -o ./dist/output.css --watch

# Open index.html in browser

```
